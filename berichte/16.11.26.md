## 1. Netzwerkverbindung mit NAT und Bridged Mode

In diesem Versuch wurden die beiden virtuellen Maschinen Kali Linux und Metasploitable miteinander verbunden. Dabei wurden die Netzwerkmodi **Bridged** und **NAT** verwendet und miteinander verglichen.

### 1.1 IP-Adressen im Bridged Mode

| Gerät | IP-Adresse |
|---|---|
| Kali Linux | `192.168.1.52` |
| Metasploitable | `192.168.1.51` |
| Host-System | `192.168.1.50` |
| Standard-Gateway | `192.168.1.50` |

### 1.2 IP-Adressen im NAT-Modus

| Gerät | IP-Adresse |
|---|---|
| Kali Linux | `192.168.40.142` |
| Metasploitable | `192.168.40.147` |
| Host-System | `192.168.40.1` |
| Standard-Gateway | Laut vorhandener Aufzeichnung keines |

### 1.3 Vergleich der Netzwerkmodi

- **Bridged Mode:** Die virtuelle Maschine wird über eine virtuelle Netzwerkbrücke mit dem Netzwerk des Host-Systems verbunden. In diesem Versuch wurde dafür die Ethernet-2-Verbindung des Hosts verwendet. Die VM befindet sich dadurch im selben Netzwerk wie andere Geräte.
- **NAT-Modus:** Die virtuellen Maschinen verwenden das VMware-Netzwerk `VMnet8`. Dabei übernimmt ein virtueller Router die Netzwerkadressübersetzung. Verbindungen von außerhalb des NAT-Netzes zu einer VM sind normalerweise nicht direkt möglich, sofern keine entsprechende Weiterleitung eingerichtet wurde.

## 2. Dateitransfer von Metasploitable zu Kali Linux

Für die Übertragung einer Textdatei wurde der bereits auf Metasploitable laufende Webserver verwendet. Die Datei wird über HTTP bereitgestellt und anschließend mit `curl` auf Kali Linux heruntergeladen.

### 2.1 Webserver und Prozess überprüfen

Mit `ps ax` werden die aktuell laufenden Prozesse angezeigt:

```bash
ps ax
```

In der Prozessliste kann überprüft werden, ob der Webserver **Apache2** aktiv ist.

Um zu kontrollieren, ob Apache2 auf dem HTTP-Standardport 80 Verbindungen entgegennimmt, kann folgender Befehl verwendet werden:

```bash
sudo netstat -tlpn | grep apache
```

Apache2 verwendet in dieser Übung Port `80`.

### 2.2 Verzeichnis des Webservers

Das in der vorhandenen Versuchsdokumentation verwendete Webverzeichnis lautet:

```text
/var/www/test/
```

Dateien, die über den entsprechenden Webpfad erreichbar sein sollen, müssen in diesem Verzeichnis abgelegt werden.

### 2.3 Textdatei erstellen

Auf Metasploitable wird mit `echo` eine Textdatei erstellt:

```bash
echo Hallo | sudo tee Hallo.txt
```

Anschließend wird die Datei in das Webserver-Verzeichnis verschoben:

```bash
sudo mv Hallo.txt /var/www/test/
```

### 2.4 Datei auf Kali Linux herunterladen

Auf Kali Linux wird die Datei mit `curl` vom Webserver abgerufen:

```bash
curl http://192.168.40.147/test/Hallo.txt -o Hallo.txt
```

Damit wird der Inhalt der Datei vom Metasploitable-Webserver heruntergeladen und lokal unter dem Namen `Hallo.txt` gespeichert.

## 3. Dateitransfer von Kali Linux zu Metasploitable

Für die Übertragung in die Gegenrichtung kann auf Kali Linux ein einfacher Python-Webserver gestartet werden.

### 3.1 Python-Webserver starten

Zuerst wird auf Kali Linux in das Verzeichnis gewechselt, in dem sich die zu übertragende Datei befindet. Danach wird der Webserver gestartet:

```bash
python3 -m http.server 8000
```

Der Server stellt die Dateien dieses Verzeichnisses über Port `8000` bereit.

### 3.2 Datei auf Metasploitable herunterladen

Auf Metasploitable wird die Datei mit `curl` vom Kali-System abgerufen:

```bash
curl http://192.168.40.142:8000/Test.txt -o Test.txt
```

Die Datei `Test.txt` wird dadurch im aktuellen Verzeichnis von Metasploitable gespeichert.

## B. Übung 2.2 – Dateitransfer über einen Webserver

Dieser Abschnitt fasst die ergänzenden Arbeitsschritte aus dem zweiten Aufgabenblatt zusammen. Die grundlegenden Befehle und der Dateitransfer von Metasploitable zu Kali Linux sind bereits in Kapitel 2 beschrieben.

### B.1 Laufende Prozesse untersuchen

Auf Metasploitable werden die aktiven Prozesse mit folgendem Befehl aufgelistet:

```bash
ps ax
```

In der Ausgabe wird nach dem Prozess des Webservers gesucht. In dieser Übung handelt es sich um Apache2.

Bei einer langen Ausgabe kann mit `more` seitenweise weitergeblättert werden.

### B.2 Netzwerkdienste und Ports anzeigen

Mit folgendem Befehl werden aktive TCP- und UDP-Listener mit Prozessinformationen angezeigt:

```bash
sudo netstat -tlpn
```

Um die Ausgabe auf Apache-bezogene Einträge einzugrenzen, kann `grep` verwendet werden:

```bash
sudo netstat -tlpn | grep apache
```

Der in der Übung relevante Standardport für HTTP ist `80`.

### B.3 Webserver-Verzeichnis feststellen

Mithilfe der Informationen aus `ps` und `netstat` wird der verwendete Webserver ermittelt. Danach wird festgestellt, in welchem Verzeichnis dieser seine Dateien bereitstellt.

Im bisherigen Bericht ist dafür folgendes Verzeichnis dokumentiert:

```text
/var/www/test/
```

### B.4 Datei im Webserver-Verzeichnis bereitstellen und herunterladen

Die Textdatei wird auf Metasploitable erstellt und in das Webserver-Verzeichnis verschoben. Anschließend wird sie von Kali Linux mit `curl` heruntergeladen. Die vollständigen Befehle dazu stehen in Kapitel 2.3 und 2.4.

**Ergebnis/Kontrolle:** Nach dem Download kann auf Kali Linux mit folgendem Befehl überprüft werden, ob die Datei vorhanden ist und den erwarteten Inhalt enthält:

```bash
cat Hallo.txt
```
