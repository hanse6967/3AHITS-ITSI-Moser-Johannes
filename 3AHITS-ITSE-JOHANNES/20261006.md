## vs code installation

- Ändere dein Tastatur Layout auf deutsch 
```sh
setxkbmap de
```


- gib diesen code im kali Linux terminal ein
```sh
wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"
sudo apt install ./vscode.deb
code --version
```
- Die Befehle ur nacheinander eingeben 

- Zum vs code start diesen Befehl in das Terminal eingeben

```sh
code .
```

## Github Einrichtung

- Gib im Terminal diese Befehle ein verwende aber statt John Doe deinen Echten Namen und deine Email die mit Github verbunden ist
```sh
git config --global user.name "Jon Doe"
git config --global user.email "deine@email.at"
```
- Danach den Link des Github Repository einfügen in diesem Befehl (**Link muss in denn Klammern stehen**)

```sh
git clone <GitHub Repo Link>
```
- Wenn du fertig bist mit allem und die vm schließen willst mach es mit diesem Befehl
```sh
sudo shutdown now
```
